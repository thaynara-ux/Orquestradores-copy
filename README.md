# Orquestradores-copy

Repositório criado para o treinamento de Git e GitHub.

## Sobre o projeto

Este repositório serve como ambiente de prática para aprender o fluxo de trabalho com Git e GitHub, incluindo:

- Criar e clonar repositórios
- Criar Issues para rastrear tarefas
- Trabalhar com branches
- Fazer commits
- Abrir Pull Requests
- Realizar merge

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/thaynara-ux/Orquestradores-copy
   ```
2. Entre na pasta:
   ```bash
   cd Orquestradores-copy
   ```
3. Crie uma branch para sua tarefa:
   ```bash
   git checkout -b feature/nome-da-tarefa
   ```
